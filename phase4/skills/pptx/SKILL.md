# PPTX Skill
Read slide text in slide order. Create a simple 16:9 OOXML presentation with Arial text, title and body content. Targeted edits replace text in slide text runs while copying every unrelated package entry unchanged. Do not claim that a simple generated deck preserves arbitrary custom masters, animations, charts, or speaker notes when creating from scratch.
