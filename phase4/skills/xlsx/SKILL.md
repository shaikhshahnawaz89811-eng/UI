# XLSX Skill
Read workbook sheet names, cell references, values and formulas. Handle shared strings and inline strings. CSV/TSV are treated as tabular spreadsheet input. Create XLSX with Arial defaults and deterministic worksheet XML. Targeted cell edits preserve unrelated package entries and existing cell style metadata when possible. Do not invent calculated formula results; expose formulas when cached values are unavailable.
